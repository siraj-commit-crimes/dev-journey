# Launch Checklist

Go through this before every store goes live.

## Settings
- [ ] Store name, email and address correct
- [ ] Currency set to USD
- [ ] Taxes set correctly (or turned off)
- [ ] Domain connected and HTTPS working

## Payments
- [ ] Cash on delivery turned on, with clear instructions
- [ ] Whish / card payment tested (if included)
- [ ] Test order placed and cancelled

## Delivery
- [ ] Shipping zones created for each region
- [ ] Fees match the client's onboarding form
- [ ] Free-delivery threshold works (if any)

## Products
- [ ] All products have photos, prices and descriptions
- [ ] Variants (sizes/colors) and stock correct
- [ ] Collections set up

## Languages and pages
- [ ] Arabic shows right to left, no missing translations
- [ ] About, Contact, Return policy pages published
- [ ] Policies linked in the footer

## Channels
- [ ] WhatsApp button opens the right number
- [ ] Order notifications reach the client
- [ ] Instagram / Facebook shop synced (if included)

## Final
- [ ] Checked on a phone (most customers buy on mobile)
- [ ] Page speed OK
- [ ] Store password removed
- [ ] Client trained on adding products and handling orders
- [ ] Final payment received
