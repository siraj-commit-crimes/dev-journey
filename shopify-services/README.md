# Shopify Services — Lebanon

My plan for building Shopify stores for small businesses in Lebanon,
starting local and going worldwide later.

- Full plan (shareable doc): https://claude.ai/artifact/MKm3wpZhcKPhk7H1aGNqtW
- Portfolio site: [`docs/index.html`](../docs/index.html), published with GitHub Pages
- Instagram: [@theshopifyexpertlb](https://instagram.com/theshopifyexpertlb)

## The offer

Real stores for brands that sell on Instagram and WhatsApp today:
cash on delivery, delivery fees by region, orders sent to WhatsApp,
English and Arabic.

| Package   | Starting from | Main things included                                        |
| --------- | ------------- | ----------------------------------------------------------- |
| Starter   | $350          | Up to 30 products, COD, delivery zones, WhatsApp button      |
| Business  | $700          | Starter + 2 languages, 100 products, Instagram/FB sync, SEO  |
| Custom    | $1,500        | Custom design, code changes, card payments, migration        |
| Care plan | $50 / month   | Updates, new products, fixes, monthly report                 |

Terms: 50% upfront, 50% at launch. The client pays for their own Shopify plan and apps.

## Roadmap

1. **Foundation (weeks 1–2):** Shopify Partner account, 3 demo stores, portfolio site live
2. **First clients (weeks 3–6):** network + 10 Instagram DMs a week → 3 paying clients
3. **Make it repeatable (months 2–4):** base theme, care plans, referrals
4. **Go worldwide (months 6+):** English case studies, Upwork/Fiverr, Shopify Partner Directory

## Publishing the portfolio site

1. Merge this branch into `main`.
2. On GitHub: **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, Branch: `main`, Folder: `/docs`, then **Save**.
4. After a minute the site is live at `https://siraj-commit-crimes.github.io/dev-journey/`.

Before sharing it, replace `961XXXXXXXX` in `docs/index.html` with your WhatsApp number.
